# assumption-trace — 가정 출처 추적

IM의 숫자는 둘 중 하나다. 출처가 있는 숫자, 아니면 작성자의 희망.
이 게이트는 모든 숫자를 첫 번째로 만들거나, 두 번째라고 정직하게 표시하게 한다.

## 트리거
- IM 본문이나 모델 가정표에 숫자를 처음 넣을 때
- 검색 결과·뉴스·블로그에서 숫자를 옮겨올 때
- 같은 항목에 출처가 둘 이상일 때

## 절차
1. **가정표 작성** — 모든 입력값을 한 표에 모은다.
   | 항목 | 값 | 단위 | 기준연도 | 출처(문서·표·쪽) | 출처 등급 | 값 등급 |
   - 출처 등급: **1차**(공시·공고 원문·통계 원표·연구기관 보고서 본문) / **2차**(언론·업계 블로그·검색 요약)
   - 값 등급: **측정**(원자료 수치 그대로) / **추론**(원자료에서 계산) / **추측**(근거 없는 가정)
2. **기준연도 확인** — 비용 숫자는 연도마다 움직인다. 같은 보고서 안에 여러 연도가 있으면 **가장 최근 연도**를 쓰고, 옛 연도를 쓰면 이유를 적는다.
3. **2차 → 1차 승격 시도** — 2차 출처 숫자는 원문을 열어 대조한다. 원문을 못 열면 본문에 "[2차 출처]"를 표시한다. **검색 엔진 요약문은 출처로 인정하지 않는다.** 요약문은 원문을 찾는 길잡이일 뿐이다.
4. **충돌 처리** — 출처끼리 값이 다르면:
   - 정의(집계 범위·단위·기간) 차이로 설명되면 그 차이를 적고 하나를 고른다.
   - 설명이 안 되면 **그 숫자를 본문에서 뺀다.** 둘 중 마음에 드는 쪽을 고르지 않는다.
5. **추측 행 정리** — 값 등급이 '추측'인 행은 IM 본문에 "가정"으로 드러내고, stress-gate의 민감도 대상에 반드시 넣는다.

## PASS/FAIL
- **PASS** = 가정표의 모든 행에 출처·기준연도·두 등급이 있음 + 충돌 행은 해소 근거 또는 삭제 기록이 있음
- **FAIL** = 출처 빈칸, 검색 요약을 출처로 기재, 충돌을 기록 없이 한쪽 선택

## 이 스킬이 막는 실사고 (samples/solar-1mw 작업 중 실제 발생)
- **기준연도 오류**: 설비비로 1,416천 원/kW를 썼다. 원문 표를 열어보니 2023년 값이었고, 2024년 값은 1,281이었다. Equity IRR이 12.0%에서 16.1%로 바뀌는 차이다. → 절차 2
- **요약문 오류**: 검색 요약이 "육지 첫 태양광 출력제어는 2026년"이라고 했다. 원문 기사는 2024년 4월이었다. → 절차 3
- **출처 충돌**: 같은 해 RPS 정산 총액이 보도마다 1.9조 원과 4.48조 원으로 갈렸다. 집계 범위를 확인할 때까지 본문에서 뺐다. → 절차 4
