# im-parity — IM ↔ 모델 ↔ 가정표 정합

모델을 고치면 IM 본문 어딘가에 옛 숫자가 남는다. 요약 페이지, 표 캡션, 면접 대비 메모.
읽는 사람은 그중 하나만 봐도 모델 전체를 의심한다.

## 트리거
- IM·기고문 발행 직전
- 가정이나 모델 구조를 바꾼 직후

## 절차
1. **숫자 추출** — IM 본문에서 숫자를 전부 뽑는다 (요약·본문·표·각주·부록).
2. **3자 대조표**
   | IM 위치 | IM 값 | 모델 값 | 가정표 값·출처 | 일치 |
   - 모델 결과(IRR·DSCR 등)는 모델 값과, 입력(가격·비용 등)은 가정표와 대조한다.
3. **옛 값 검색** — 이전 버전의 핵심 숫자(바뀌기 전 IRR, 옛 단가 등)로 본문을 검색해 남은 곳이 없는지 확인한다.
4. **임시 표시 제거** — "[확인 필요]", "[엑셀 결과로 교체]" 같은 작업 표시가 남았는지 검색한다. 남았으면 발행하지 않는다.
5. **서술 정합** — 숫자만 맞고 문장이 옛 결론을 말하는 곳을 찾는다 (예: 숫자는 1년 차인데 문장은 "15년 차가 가장 빠듯하다").

## PASS/FAIL
- **PASS** = 대조표 전 행 일치 + 옛 값 0건 + 작업 표시 0건 + 서술 모순 0건
- **FAIL** = 한 곳이라도 불일치

## 이 스킬이 막는 실사고 (samples/solar-1mw)
- **요약 드리프트**: 이용률 가정을 15%에서 15.4%로 바꾼 뒤에도 본문에 "1MW, 이용률 15%면 1,314MWh"가 남아 있었다. 요약 줄의 "이용률 1%p ≈ IRR 2.9%p"도 옛 모델 값이었다(새 값 3.5%p). → 절차 3·5
