# deal-thesis-gate — 수익의 출처 + 비용 전수표

인프라 자산의 수익은 공짜가 아니다. 누군가 계약으로, 규제로, 또는 대안이 없어서 지불한다.
그 '누군가'를 못 대면 IRR이 아무리 좋아도 근거가 없는 숫자다.

## 트리거
- 새 딜·가상 프로젝트 검토 시작 (모델을 만들기 전)
- 수익 구조(계약 형태, 판매처, 요금 체계)가 바뀌었을 때

## 절차
1. **수익 출처 3필드** — 문장으로 채운다. 하나라도 비면 진행하지 않는다.
   - **지불자**: 누가 돈을 내나 (장기 구매계약 상대방, 규제 요금, 도매시장, 임차인)
   - **이유**: 왜 그 가격을 내나 (의무 이행, 대체재 부재, 정책 보조, 입지 독점)
   - **지속성**: 그 이유가 계약기간·대출기간 동안 유지되나. 무엇이 깨면 끝나나 (제도 개편, 계약 해지 조항, 경쟁 공급)
2. **진입장벽** — 왜 다른 사업자가 같은 수익을 가져가지 못하나 (인허가, 계통 접속권, 부지, 입찰 낙찰). 장벽이 없으면 수익률은 경쟁으로 깎인다고 적는다.
3. **비용 전수표** — 아래 행을 전부 채운다. 행마다 값·출처·등급(assumption-trace 기준).
   | 구분 | 항목 |
   |---|---|
   | 개발 | 부지 확보, 인허가, 계통연계, 개발 수수료 |
   | 건설 | 설비·시공(EPC), 예비비, 건설기간 이자 |
   | 운영 | 운영유지(O&M), 안전관리, 보험, 주요 부품 교체 적립 |
   | 부지 | 토지 매입 또는 임차료 |
   | 금융 | 이자, 금융 수수료, 적립계좌(DSRA) |
   | 세금 | 법인세, 지방세, 재산세 |
   | 해체 | 철거·원상복구 |
4. **0 처리** — 값이 0인 행은 🔴 표시 + "왜 0인가" 한 문장. 근거 없는 0은 FAIL.
5. **출력** — 수익 출처 3필드 → 진입장벽 → 비용 전수표 → 판정. 이 표를 IM 2장(사업구조)과 4장(재무)의 근거로 넘긴다.

## PASS/FAIL
- **PASS** = 3필드 문장 완성 + 진입장벽 서술 + 전수표 전 행 채움 + 🔴 행마다 정당화
- **FAIL** = 지불자를 못 댐, 또는 근거 없는 0이 한 행이라도 있음

## 이 스킬이 막는 실사고 (samples/solar-1mw)
- **비용 누락**: 첫 모델에 토지 임차료와 법인세가 없었다. 둘을 넣고 토지만 빼서 다시 돌리면 Equity IRR이 20.5% → 16.1%로 4.4%p 차이가 난다. → 절차 3의 '부지'·'세금' 행과 절차 4
- **0으로 둔 개발비**: 인허가·계통연계 비용은 지금도 모델 밖에 있다. 이 게이트를 통과하려면 값을 찾거나, IRR이 '상한'이라고 본문에 명시해야 한다.
